# 💎 Leenardo - Graded Language Learning Platform

Bu klasör, seviyelendirilmiş Türkçe haberler web sitesinin tüm dosyalarını içerir.

## 🚀 Nasıl Açılır?
- **`index.html`** dosyasına çift tıklayarak tarayıcınızda (Chrome/Safari) hemen açabilirsiniz.

## 📁 Dosyalar
- **`index.html`**: İnteraktif web sitesi (kategori filtreleme, A1-C2 seviye seçimi, sesli okuma, anlama testi, hover çeviri).
- **`articles.json`**: Haberlerin ve CEFR seviyelerinin yer aldığı veritabanı.
- **`news_pipeline.py`**: Python otomasyon ve seviyelendirme betiği.
- **`worksheets/`**: Preply derslerinde Google Docs veya Word'e kopyalayabileceğiniz hazır çalışma kağıtları.
